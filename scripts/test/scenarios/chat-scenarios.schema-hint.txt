chat-scenarios JSON (informal contract)
- defaults: merged into every POST body; must include siteId for your run. agentId optional (runner resolves from ui.xml or default UUID).
- turns[].prompt: user message (required).
- turns[].request: optional object merged on top of defaults for that turn only (e.g. switch authoringSurface to preview for translate).
- turns[].expect: optional assertions on SSE telemetry — recipeId, recipeOutcome, toolsAny, toolsAll, forbidTools, maxToolStarts.
- turns[].optional / turns[].skipUnless: skip turn when env unset (see run-tool-recipe-matrix.sh).
- turns[].group: intent-recipes | builtin-tools (filter with CHAT_SCENARIO_GROUP).
- turns[].freshChat: new chatId before this turn.
- Runner adds chatId (same UUID for all turns in one session) unless freshChat on a turn.
